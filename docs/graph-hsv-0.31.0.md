# 구매 그래프 수동 색상 0.31.0

‘다른색’에서 채도·밝기 평면과 색조 막대를 움직여 색상을 고릅니다. 방향키·Home/End·Shift 조합도 지원합니다. 조작은 색상 창 안에서만 반영하며 선택/Enter 후 부모 필터에 전달하고 최종 적용(F8) 때 그래프를 바꿉니다.

## 원본 관찰과 실제 REA 경계

원본 다른색을 열어195×170 평면·195×16 색조 막대·10×10 평면 그립/6×16 색조 그립·6자 HEX 입력/선택을 읽었습니다. 색 입력·드래그·색상 선택·필터 적용은 하지 않았고 Escape로 닫았습니다. 이후 그래프를 해제하고 일반 집계로 복귀했습니다. 회사 범주·숫자·업무자료는 수집하지 않았습니다.

기존81본문의 실제 REA 참조25개에 대응합니다. UIKit 후보는 SV x/195와(170−y)/170, 색조 x/195를 clamp하고 마우스 누름/이동/뗌과 전역 이벤트 정리를 정의합니다. 회색·검정 HEX 입력은 기존 색조를 유지합니다. 실제 HSV↔RGB와8bit 반올림은 미확보 globalThis.tinycolor에 위임됩니다. 후보 그립의−8px/폭기준 clamp와 현재 DOM 그립 크기도 같다고 보장할 수 없습니다. 현재 legacy 셀 어댑터/위젯 호출 연결은 여전히 미확인입니다.

## 자체 구현·검사

- 이전 브라우저 색상 입력을195×170 평면/195×16 막대로 바꿨습니다. 위치는 실제 client bounding rect로 나누고 범위를 제한하며 그립을 중앙에 놓습니다. 이는 원본 후보의 고정 pageoffset/그립 보정과 구분하는 자체 정책입니다.
- HSV는 색조0~360도·채도/밝기0~1로 보관합니다. 독립 변환식과 JavaScript 부동소수 채널의 Math.round를 사용합니다. 원본 tinycolor 반올림과 같다고 주장하지 않습니다. 기본/보조색·검정/회색·360끝점·256종8bit 왕복·잘못된 범위를 검사합니다.
- 드래그는 팔레트 로컬 HSV를 보존하고 HEX/미리보기를 갱신합니다. 입력한 유채색은 색조를 갱신하지만 회색/검정은 선택 색조를 유지합니다. 잘못된 HEX는 마지막 유효 상태를 바꾸지 않고 선택 단계에서 오류를 안내합니다.
- Pointer ID·오른쪽 버튼 무시·capture/밖 이동 clamp·up/cancel/lostcapture와 전역 리스너 제거를 처리합니다. 키보드·터치/Pointer 지원은 자체 추가이며 원본의 동작/부재로 설명하지 않습니다. 방향키는 채도/밝기1%·색조1도, Shift는10%·10도입니다.
- 자식 조작/취소는 현재 전표·표·그래프에 쓰지 않습니다. 선택 후 부모 필터 적용까지 구분하고 이탈/닫기 시 두 창과 전역 이벤트를 정리합니다. 기존77색·3/6HEX·범주 override·복원·CSV/인쇄는 유지합니다.
- 실제 조회 전용 메뉴에서 키보드로 초록을 골라 팔레트 선택→필터 적용→CSV/인쇄까지 합성 검사하며 저장 내용·원시 숫자가 바뀌지 않는지 확인합니다. 별도 실 브라우저/터치 시각 검증은 미완료입니다.

새12개·관련 집중124개의 완료 집계와 전체 결과는 `evidence/global-rea-20261018/graph-hsv/validation.json`에 기록합니다. 독립 정적 검토에서 확정 결함은 발견되지 않았습니다. 저장 형식/DB 스키마 변경은 없습니다. 원본 tinycolor/어댑터·CSS/디바이스 픽셀·설정/랭킹/소계·백엔드/출력 동등성과 호스팅 로그인 업무 검증은 남아 있습니다.81본문19,600,813B 및 이전 부분·timeout·OOM을 보존하며 신규 GET·원본 JS 실행은 없습니다.
