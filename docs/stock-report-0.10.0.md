# 출력물 재고현황 0.10.0

재고 I → 출력물 → 재고현황 → 기본 재고현황(E040701)을 원본 화면과 공개 JavaScript에 대조해 전용 조회로 구현했다. 이전의 시작일·종료일과 창고별 기초/입출고를 나열하던 공통 현황 대신, 기준일 한 날짜의 품목별 재고를 표시한다. 창고별재고·관계별·다규격·BOM·잔량분석·재고수불부·재고변동표·일보의 추가 재현은 이번 범위에 포함하지 않는다.

## 계산과 자료 보존

기초재고와 기준일 이하의 활성 전표 수불을 조회한다. 선택 창고를 합산한 후 품목·수량 범위·안전재고 조건을 적용하며 미확인·취소·미래 전표를 제외한다. 안전재고는 창고 하나 선택 시 해당 설정, 전체·복수 창고는 품목 설정을 사용하는 자체 정책이다. 수량 셀 안전재고 강조는 기본 전체 창고 조회에만 적용한다.

금액은 현재 품목에 등록된 입고단가 원값 × 재고수량이다. 원본 서버의 평균원가·선입선출·특별단가·VAT 역산·재고 평가와 같다고 입증하지 않았다. 기본 조회에 수량 0인 등록 품목을 포함하는 것도 자체 정책이며 원본 숫자 검색식의 전체 문법은 미확인이다.

조회·정렬·수불·CSV·인쇄는 업무 자료를 변경하지 않는다. 스키마·API·D1 변경 없이 기존 브라우저/D1 분리와 v2 백업을 유지한다. 원본 회사 자료·설정의 저장·삭제·취소·발송은 실행하지 않았으며 `sources/`를 변경하지 않았다.
