# 구매 그래프 범주 색상·팔레트 0.30.0

그래프 필터에서 각 범주의 ‘색상 선택’을 열어 기본색을 고르거나 ‘다른색’에서 직접 입력합니다. 색상 선택은 필터 초안에만 반영되며 최종 적용(F8) 때 그래프가 바뀝니다. 범주에 따로 지정한 색은 범례 색상보다 우선합니다.

## 원본 관찰·실제 REA·자체 정책

원본 GraphFilter의 범주 색상 링크를 열어11열×7칸의77개 기본색 CSS 배경을 읽었습니다. ‘다른색’을 열어6자 입력칸과 선택 버튼을 확인했습니다. 입력·기본색 클릭·선택·최종 필터 적용은 하지 않았고 Escape로 닫았습니다. 기본색 목록은 일반 UI 색상이며 회사 범주명·숫자·업무 기록을 증빙/실행 파일에 보관하지 않았습니다.

기존81본문의 실제 REA 참조22개를 연결했습니다. UIKit 후보는 외부 PresetComponent를 받아 프리셋 값 전달 후 색상 레이어를 닫으며, 다른색은 수동 HSV/입력 영역을 토글합니다. 수동 색상은 로컬 상태이고 선택 버튼이 값을 전달합니다. 다만 현재 legacy 셀의 [label,color]와 UIKit 이벤트 사이 어댑터는 미확인입니다.77색 생성 코드 자체도 확보되지 않았습니다. 현재 적용 규칙·반올림·취소 복구가 모두 동등하다고 주장하지 않습니다.

자체 기본색은 관찰한77색입니다. 데스크톱11열×7칸, 모바일5열/44px 선택 영역으로 배치합니다. 다른색은 이번 버전에서 브라우저 색상 입력과 HEX 입력을 사용하는 자체 대체입니다. 원본 HSV 평면/색조 조작은 다음 대조 범위입니다. 원본 후보의 CSS 변환보다 좁은 엄격한3/6자리 HEX만 받아 소문자6자리로 정규화합니다. UI는 # 없는 입력도 허용합니다. 원본 validator와 같은 것으로 설명하지 않습니다.

## 합격 조건

1. 프리셋은 부모 필터에 즉시 색을 전달하고 색상 창을 닫습니다. 수동 입력은 선택/Enter 전까지 로컬 상태입니다. 취소는 부모 필터를 유지하고, 부모 닫기/화면 이탈은 자식도 제거합니다. 자식 F8은 부모 적용/뒤 검색으로 전파하지 않습니다.
2. 범주 override는 안정 axis 튜플에 연결합니다. 범례를 잠시 같은 색으로 바꿨다가 다른 색으로 바꿔도 명시 범주색은 남습니다. 사용자가 범주색 자체를 현재 범례색으로 선택하면 상속으로 돌아갑니다.
3. 입력칸에서 바로 F8을 누르는 경우도 클릭과 같이 범례·범주 색을 정규화합니다. 잘못된 색은 현재 그래프·표·인쇄 대상을 바꾸지 않습니다. 임의 CSS/이름/alpha 변환은 지원하지 않습니다.
4. 성공 필터의 키와 색상 맵은 대기 조건과 분리해 복사합니다. 선택 해제한 범주의 색도 현재 범주 안에서 보관합니다. 사라진 범주색은 스냅샷에서도 제거하며 다시 생겨도 자동 선택/색 복구하지 않습니다. 새 검색은 기본색/전체 범주로 시작합니다.0.29 필터에 색상 맵이 없어도 복원합니다.
5. 그래프/인쇄는 범주색과 범례색을 반영하고 CSV·표의 전체 숫자는 유지합니다. 흰색·0 값 표시에도 윤곽선을 남깁니다. 전표·재고·번호·배분·저장 형식·DB 스키마는 변경하지 않습니다.

새 검사12개와 관련 집중112개, 전체 완료 결과는 `evidence/global-rea-20261018/graph-colors/validation.json`에 기록합니다. 독립 검토에서 범례 변경이 명시 override를 지우는 문제와 입력 직후F8의 정규화 차이를 수정하고 회귀 경로를 추가했습니다. 이전 상속 검사 실행은 완료 집계가 없어 별도 미완료 로그로 보존하고, 모든112개를 완료한 재실행을 사용합니다.
