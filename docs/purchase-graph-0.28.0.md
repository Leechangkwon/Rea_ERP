# 구매 집계 그래프 0.28.0

구매현황에서 집계를 선택하고 집계조건을 지정한 뒤 ‘그래프로 보기’를 켭니다. 수량·공급가액·부가세·합계 중 지표를 골라 검색하면 성공한 집계표 위에 막대 그래프를 표시합니다. 기본 지표 수량과 가로 막대 표현은 자체 정책입니다.

## 원본 관찰과 실제 REA 근거

- 원본 구매현황의 집계·품목별에서 그래프를 체크해도 검색 조건에 머물렀습니다. 검색 후 30개 이상 변환 확인과 상위10개 권장 안내가 나왔고, 읽기 전용 확인 후 SVG가 표시됐습니다.
- Search(F3)로 조건을 열어 그래프를 해제하고 다시 검색했습니다. 원본은 품목별·수량·공급가액·부가세·합계의 일반 표로 복귀했고 표시 중인 그래프는 없었습니다. 회사별 범주·숫자·업무 자료·스크린샷을 보관하지 않았습니다. 원본 저장·설정 적용·주 입력행 조작은 없었습니다.
- 기존78본문의 실제 REA 참조159개를 연결했습니다. V56에는 그래프 전용 조회와 기본 bar 설정이 있습니다. X는 선택한 집계조건, Y는 현재 양식의 decimal 메타데이터 후보이며 첫 후보를 기본값으로 잡습니다. 원본 기본 지표가 수량이나 공급가액이라는 근거는 없습니다.
- 외부 graph.data와 그래프 렌더러에 최종 변환을 위임합니다. 현재 구매 화면의 정확한 설정 진입·차트 종류·지표 후보·렌더링·상호작용·인쇄·서버 계산은 미확인입니다. 공통 본문의 기존 의미 분석 OOM과 렌더러 timeout/OOM을 그대로 보존했습니다. 신규 GET/원본 실행 없이 78본문·19,149,569B를 유지합니다.

## 자체 구현과 합격 조건

1. 구매 집계만 지원합니다. 상세 조회와 다른 문서 현황의 그래프는 실행하지 않습니다. 집계 조합 전체를 그대로 표시하고 기본 지표는 수량입니다.
2. 성공한 집계의 records 순서와 유한한 원시 숫자를 사용합니다. 동일 표시명이나 구분자가 있는 라벨도 axis 전체 튜플로 구분하며 다시 합산하거나 정렬하지 않습니다. 값과 표의 대응을 유지합니다.
3. 0·음수·양음수 혼합과 큰 유한값을 포함합니다. 좌표를 최대 절대값으로 정규화합니다. 모든 막대의 SVG 열 폭은 동일한 고정 값 열을 사용합니다. 긴 값은 값 열 안에서 줄바꿈합니다.
4. 체크박스 checked와 지표를 임시 검색 조건에 보관하고, 성공한 결과의 그래프와 구분합니다. 검색·F8·날짜 단축 조회에서만 적용합니다. 30개 이상이면 변환 확인을 받고 상위10개로 임의 축소하지 않습니다. 취소·검증 실패·무자료는 이전 표·그래프·출력 대상을 유지합니다. 원본의 취소 후 처리 자체는 관찰하지 않았습니다.
5. 스냅샷 복원은 성공한 조건으로 재조회하며 변환을 다시 묻지 않습니다. 수정 중 체크/지표는 별도로 되돌립니다. 데이터 변경으로 복원이 실패하면 표·그래프·출력 대상을 함께 제거합니다. 예전 스냅샷은 그래프 꺼짐·수량을 기본값으로 사용합니다.
6. 다시작성은 그래프를 끄고 수량으로 초기화합니다. 기존 성공 결과는 다음 검색 성공까지 유지합니다. 메뉴를 현황으로 바꾸면 그래프 조건이 해제됩니다.
7. CSV는 기존 집계표의 전체 열·숫자를 유지합니다. 인쇄에는 성공한 그래프·지표·통화·기간·축/분류/정렬 기준을 함께 전달합니다. 금액은 실제 SelfCore 금액 자릿수, 수량은 일반 숫자 설정을 사용하며 원시 값은 바꾸지 않습니다.
8. 조회·체크·지표 변경·초기화·인쇄는 전표·재고·번호·배분을 쓰지 않습니다. 실제 조회 전용 메뉴와 인쇄/CSV, 구매실 편집 후 성공 그래프 재계산 및 대기 조건 보존을 합성 검사합니다. 저장 형식·DB 스키마 변경은 없습니다.

## 검사와 남은 범위

집중 검사 로그와 완료된 전체 검사 집계는 `evidence/global-rea-20261018/purchase-graph/validation.json`에 기록합니다. 금액 표시와 SVG 폭 문제를 독립 검토에서 발견해 수정했고 실제 SelfCore 설정 회귀 검사를 추가했습니다. 수정 전 전체 실행은 중단 로그로 구분합니다.

원본 5종 차트·보조 축·추세선·범례·제목/극값·필터·상세 이동·이미지 출력·양식/서버 계산과 동등하다고 주장하지 않습니다. 원본 관찰, 실제 REA, 자체 정책 및 합성 검사를 각각 기록했습니다. 호스팅 로그인 후 업무 화면과 실제 브라우저 시각 검증은 미완료입니다.
