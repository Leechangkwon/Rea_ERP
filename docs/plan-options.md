# Option / 사용자 양식 확장

대상: C:\vibe\ecount-rea. 기존 버전 0.2.0 → 0.3.0. 원본 ERP에서는 관찰만 하고 저장하지 않는다.

구현 완료:
- FormCore: 메타데이터의 저장/선택/병합/기본 복원/조건 우선순위, 안전한 수식 파서, 입력 검증, 백업 검증.
- FormOptions: 이름 있는 양식 복사/편집/항목 배치/BODY/페이지/조건 설정 UI.
- InventoryUI: 전표·기초등록·표·검색·인쇄·CSV에 양식을 적용하고 추가항목 값을 보존.
- InventoryCore: 저장 시 필수/계산 검증, 기존 v2 자료 호환, JSON 백업에 설정 포함.

원본 관측: 품목등록 Option의 양식설정/조건양식설정/검색항목설정; 기본(수정불가) 양식 목록; BODY설정/페이지설정/기본값복원; 기본 양식 저장 제한 안내. 읽기 전용으로 닫고 메인 복원. 세션/회사별 설정은 복사하지 않음.

검증: 옵션 핵심 18개 + 옵션 DOM 14개 통과, 기존 메뉴/재고 회귀 포함 80개 통과. 실제 브라우저에서 필수/계산/값 보존/조건 전환/조회 CSV/인쇄/백업 확인.

범위: 브라우저에 보관하는 단일 사용자 로컬 설정. 원본의 모든 옵션/권한/서버 규칙과 동일함을 주장하지 않는다. 복합 조건·역할별 접근·원본 회사별 업무설정은 별도 범위.
