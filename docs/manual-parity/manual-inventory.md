문서 ID, 한국어 제목, 분류, URL 또는 실제 페이지/영상 시각, 확인일, 개정 표시, 원문 해시, 요구사항 ID를 기록한다. 로그인 세션 쿼리·계정·업무자료는 기록하지 않는다. 원문과 이미지는 .artifacts에만 두고 커뮤니티에는 요약 요구사항과 공개 링크만 올린다. 로그인용 도움말과 API의 전체 개수가 미확정이므로 전체 수집 완료율은 계산하지 않는다.
