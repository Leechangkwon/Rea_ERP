# 구매 그래프 필터 0.29.0

구매 집계 그래프 아래 ‘필터’를 열어 범주를 고르고 범례 색상을 바꾼 뒤 적용(F8)을 누릅니다. 그래프만 즉시 바뀌며 집계표와 CSV는 전체 결과를 유지합니다. 닫기와 Escape는 편집 중인 선택·색상을 버립니다.

## 확인한 원본과 실제 REA

원본 구매 그래프의 필터 창에서 범주·범례 체크 영역과 적용(F8)·닫기를 관찰했습니다. 선택·색상 변경과 적용은 실행하지 않았습니다. 검색으로 보였던 입력은 창 뒤의 현황 빠른검색이었습니다. 입력 시도는 덮인 창 때문에 차단됐고 실제 입력·Enter는 없었습니다. 이 입력을 필터 검색 기능으로 기록하지 않습니다.

실제 DOM의 공개 script[src] 세 URL을 각각1회 비인증 GET하고 gzip 복원·SHA 검증 후 고정 REA6.4.0으로 분석했습니다. 원본 JS는 실행하지 않았습니다. graph.data61,678B·browser.graph384,006B·GraphFilter5,560B는 정적/의미 분석이 모두 완료됐습니다. 누계81본문19,600,813B, 정적 완전80/부분1·의미 완전76/부분1/timeout2/OOM2입니다. 이전78본문의 부분·중단은 그대로 남깁니다.

공개 GraphFilter는 그룹 체크와 개별 체크, 범주/범례 색상 링크, 적용F8·닫기를 만듭니다. 이 페이지가 생성하는 검색·Enter 검색·Reset은 없습니다. 적용은 범주가 있는 경우 범주와 범례를 각각 하나 이상 요구하고 체크·색상 메시지를 보낸 뒤 닫습니다. 범주 없는 pie 분기는 범례만 요구하지만 자체 화면은 단일 지표 막대입니다. 원본 Close는 메시지 없이 닫지만 색상 객체 참조 공유와 기반 Escape/X의 취소 보장은 미확인입니다.

추가 graph.data에서 포맷된 축 캡션을 기준으로 합산하고 상위/하위10개를 고른 뒤 필터를 적용하는 코드를 확보했습니다. 행렬별 그룹·동률 처리가 서로 다릅니다. 실제 현재 팝업 메시지→뷰어 연결과 서버/SID/양식 숫자 규칙은 미확인입니다. 이 코드를 확보한 사실을 실행·렌더링 동등성으로 확대하지 않습니다.

## 자체 정책과 합격 조건

- 필터는 성공한 단일 지표 구매 집계 그래프에서만 엽니다. 범주 전체/개별 선택과 범례 전체/개별 선택을 제공하고 두 그룹을 검증합니다. 단일 범례의6자리 HEX 색상을 받습니다. 원본의 범주별 색상과 팔레트는 이번 범위에 포함하지 않습니다.
- 선택은 표시명이 아닌 전체 axis 튜플로 구분합니다. 원본 캡션 비교의 중복 매칭을 재현하지 않는 자체 정책입니다. 순서·원시 숫자를 유지하고 선택한 점의 축 범위만 다시 계산하며 합산하거나 업무 조회를 실행하지 않습니다.
- 적용 전 체크·색상은 독립 복사본입니다. 닫기/Escape는 결과·출력·스냅샷을 바꾸지 않습니다. 적용F8은 뒤의 검색F8로 전파하지 않습니다. 오래된 창은 새 조회 결과에 적용할 수 없고 화면 이탈 시 제거합니다.
- CSV와 집계표는 전체 열·행을 유지합니다. 인쇄에는 선택한 그래프·색상·전체/선택 행수·성공 기간/지표/기준이 들어갑니다. 미적용 검색 조건으로 인쇄 결과를 바꾸지 않습니다.
- 성공 필터의 키/색상과 대기 중 검색 체크/지표를 따로 복원합니다. 사라진 범주는 화면과 성공 필터 양쪽에서 제거합니다. 다시 나타나도 자동 재선택하지 않습니다. 선택한 범주가 모두 사라지면 표·그래프·출력 대상을 지웁니다. 새 검색은 전체 범주와 기본색으로 시작합니다. 이전 스냅샷에 필터가 없으면 전체를 표시합니다.
- 전표·재고·번호·배분·저장 형식·DB 스키마는 바꾸지 않습니다. 조회 전용 실제 경로, 인쇄/전체CSV, 창 이탈과 구매실 편집 후 재계산을 합성 검사합니다.

새 검사13개와 관련 집중100개, 전체 완료 집계·독립 검토는 `evidence/global-rea-20261018/graph-filter/validation.json`에 기록합니다. 독립 검토에서 복원 후 성공 필터에 없어진 키가 남는 문제를 수정하고 재등장 회귀 검사를 추가했습니다. 호스팅 로그인 업무·브라우저 시각 검증, 원본 메시지 수신/색상 팔레트/범주별 색상/다중 지표/5종 렌더러/설정·랭킹 UI·서버 동등성은 남아 있습니다.
