# 발주요청 저장 후 내용유지 0.17.0

발주요청 입력의 저장/내용유지를 활성화했다. 저장된 같은 요청 번호를 수정 모드로 열고 행별 거래처와 품목행 식별자를 유지한다. 다시 저장하거나 메뉴를 이동한 뒤 수정해도 요청을 중복 생성하지 않는다. 발주계획·발주서의 내용유지와 저장/신규·전자결재는 계속 미확인 범위다.

## 원본 근거

현재 로그인된 원본 발주요청입력의 저장 화살표를 열어 저장/전자결재·저장/내용유지·저장/신규를 직접 관찰했다. 저장 옵션을 실행하지 않고 Escape로 닫았다. 입력행을 조작하지 않았다. 회사 업무 자료나 세션 URL을 보관하지 않았다.

기존 공개 원문의 purchase_request_bottom_button에는 save_review와 저장/내용유지 주석이 있고, 요청 입력은 E040314 V56 메타에 연결된다. 실제 REA6.4.0으로 분석된 V56 CreateAndModifyInventoryReviewSlipUserAction은 공통 저장 프로그램이 성공한 응답의 데이터 식별자·수정 번호·일자·번호로 GET_MODIFY 재진입을 요청한다. 실패하면 성공 재진입을 하지 않는다. 현재 계정의 실제 액션 등록·서버 승인·필드별 응답·팝업 완료 경로는 실행하지 않았으므로 미확인이다. 직접 관찰한 메뉴 노출과 공개 소비자의 동작을 대조해 자체 저장 결과로 같은 전표를 다시 여는 흐름을 구현했다. 원본 서버 저장의 동등성을 주장하지 않는다.

## 자체 동작과 합격 조건

기존 구매 내용유지 처리를 발주요청에 적용했다. 기존 입력 검증·권한·브라우저 보관·연결 잔량 검사를 거친다. 성공한 저장 결과로 화면과 상세창 제목·비교 기준·초안 키를 갱신한다. 미저장 수정은 저장된 요청에 연결해 보관하고 새 요청에 섞지 않는다. 다른 화면에서 같은 요청을 바꾸면 기존 초안의 저장을 막고, 확인 후 최신 전표 다시 읽기를 제공한다. 이 비교는 같은 브라우저 앱 세션의 자체 정책이며 서버 수정 번호나 다기기 동시수정 처리가 아니다. F7 저장 이후에도 저장 식별자와 비교 기준을 갱신한다.

| 흐름 | 합격 조건 |
| --- | --- |
| 신규 → 내용유지 → 수량 수정 → 다시 저장 | 요청 한 건과 품목행 ID·행 거래처 유지, 재고 변화 없음 |
| 메뉴 이동·상세창 닫기/재열기 | 미저장 초안을 같은 요청에 복원, 저장 직후 닫을 때 불필요한 경고 없음 |
| 빈 품목·저장공간 실패·권한 회수 | 이전 자료·초안·현재 상세창 유지 |
| 다른 목록에서 같은 요청 수정 | 이전 초안 저장 차단, 재읽기 취소/확인 구분 |
| F7 후 내용유지 | 신규·내용유지 후 두 경우 모두 같은 번호, 거짓 충돌 없음 |
| 후속 발주계획 연결 | 원본 행 ID와 연결 보존, 배분된 수량보다 작게 저장 차단 |
| 조회 권한·다른 입력 종류 | 저장 제한과 미확인 저장 옵션 비활성화 유지 |

새 요청 검사7개와 기존 구매 저장/입력 검사22개, 합계29개가 통과했다. 독립 검토에서 추가로 명확한 결함은 발견하지 못했다. 전체·릴리스 결과는 `evidence/global-rea-20261018/request-save-retain/validation.json`에 기록한다. 저장 형식과 DB 스키마를 바꾸지 않았다. 호스팅 계정 로그인 후 업무 QA는 미검증이다. 관리 브라우저 로컬 미리보기 연결 부재로 대체 미리보기를 시작하지 않았다.

## 병행한 공개 정렬 코드 조사

원본 보고서 정렬창이 실제 참조한 공개 URL3개를 각 한 번 일반 GET하고 실제 REA6.4.0으로 분석했다. 새 고유 본문3개·1,906,990B, 오류·시간초과0이다. SHA로 합친 누적 코퍼스72개·12,121,611B, 정적71완료+1부분·의미70완료+1부분+1시간 중단 미확인이다. 초기3행 관찰과 달리 소스 초기화는 모든 행의 기준을 선택하면5행 미만일 때 새 행을 추가한다. 후보 요청·중복 제외·유효 행 적용 메시지·옵션에 따른 별도 양식 저장 분기는 정적으로 확인했다. 현재 보고서의 옵션·수신자와 후보 팝업 상세는 미확인이며 원본 적용을 실행하지 않았다. 근거는 `report-sort-config/`에 보관했고 앱 정렬 기능으로 활성화하지 않았다.

전역759개 경로 중 안내487개 등 기존 범위와 버튼별 미완료 항목은 유지한다. 다음 대조는 보고서 정렬 후보 선택과 적용 전 조건, 다른 입력 저장/신규 초기값·추가수량·전자결재/지급 및 전역 메뉴로 이어간다.
