# 구매 집계 축별 방향 0.20.0

구매현황 집계의 선택 축마다 오름차순·내림차순 버튼을 제공한다. 다음 검색에서 자체 그룹 코드 정렬에 반영하고 성공 결과·CSV·인쇄에 방향을 표시한다. 별도 정렬기준이 있으면 그 기준을 우선하고 동률에 축별 방향을 적용하는 자체 정책을 화면에 안내한다. 원본 일반 조회의 정렬 우선순위와 서버 비교 규칙은 미확인이다.

## 원본과 실제 REA 근거

조회 조건의 프로젝트별 버튼이 btn-asc에서 btn-desc로 바뀌는 반응을 직접 확인했다. 소계 버튼도 btn-add-sum에서 btn-unadd-sum으로 바뀌었다. 두 임시 변경을 원래 상태로 되돌렸고 해당 방향으로 원본 조회·업무·설정 저장을 실행하지 않았다. 회사 기록·세션 URL은 보관하지 않았다.

현재 원본 DOM에서 정확히 관찰한 공식 공개 URL 두 개를 쿠키 없이 각 한 번 GET했다. common 4,552,687B와 infra_common 392,801B는 SHA 중복이 없는 새 본문이다. 두 본문의 정적 분석은 실제 REA6.4.0에서 오류 없이 완료했다. infra_common의 전체 의미 분석은 완료됐고, common의 전체 의미 분석은 18.173초에 2GiB 메모리 한도로 중단됐다. 같은 전체 분석을 재시도하지 않았다. common의 선택 발췌 두 건은 별도 실제 REA 분석과 원문 좌표 매핑을 보관했으며 전체 본문의 의미 분석 완료로 승격하지 않는다. 원본 JavaScript를 실행하지 않았다.

이로써 누계는 74본문·17,067,099B, 정적 완전73/부분1, 의미 완전71/부분1/기존시간중단1/새메모리중단1이다. 본문과 발췌 수를 중복 계산하지 않는다. 원래 49본문의 액션 후보4,082개도 검증된 버튼 수가 아니다.

새 코드에서 축 선택 소비자는 sort_type=A·show_subtotal=true를 초기화하고 이미 선택된 prop을 후보에서 제외한다. free 조건 정규화는 details_target을 제거하고 방향·소계 필드를 포함한 중첩 조건을 보존한다. 그룹 생성은 조건 순서로 빈 prop과 중복 prop을 건너뛴다. 비교기간 소비자는 D를 descending:true로 변환한다. 현재 원본의 일반 조회 정렬 매퍼는 확보하지 못했으므로 비교기간 소비자를 그 경로의 확정 증거로 확대하지 않는다. show_subtotal의 그리드 설정 소비자는 있지만 서버 소계 공식과 인쇄 동등성은 미확인이다. 이번에는 축별 방향만 구현한다.

## 자체 동작과 합격 조건

- 빈 축은 방향 버튼을 비활성화한다. 축 선택은 오름차순으로 시작하며 클릭으로 전환한다. 축 교체·지우기·다시작성은 기본 방향으로 되돌린다. 다섯 번째 조건도 같은 규칙을 사용한다.
- 앞·중간 빈 조건을 건너뛸 때 방향을 같은 원래 칸의 축에 연결한다. 서로 다른 칸의 방향을 잘못 옮기지 않는다. 잘못된 방향과 조건 수 불일치는 조회 전에 거부한다.
- 자체 집계 코드의 한국어 숫자 인식 비교를 각 축의 방향에 맞게 사용한다. 금액·수량과 자료 식별자는 바꾸지 않는다. 명시 정렬을 적용한 뒤 동률은 축별 기본 순서를 유지한다. 이는 원본 우선순위가 미확인인 상태에서 정한 자체 정책이다.
- 방향 변경은 다음 검색에 반영한다. 전표 수정 후 마지막 성공 조건으로 다시 계산하고 현재 미조회 방향 설정을 복구한다. CSV는 성공한 행 순서, 인쇄·결과 제목은 성공한 방향을 사용한다.
- 조회 권한 사용자는 방향·조회·출력을 사용할 수 있고 전표 저장 권한은 늘어나지 않는다. 입력 자료 형식과 DB 스키마를 바꾸지 않는다.

## 검증과 잔여 범위

신규 합성 검사9개를 추가해 혼합 방향·다섯 번째 칸·빈 칸의 방향 대응, 명시 정렬 우선/동률, 잘못된 값, 버튼 활성화·교체·지우기·리셋, 성공/대기 방향 복구, 실제 InventoryUI에서 CSV·인쇄·조회 전용과 구매실 수정 후 재조회까지 확인한다. 관련 집중 검사는69개다. 배포 전 전체 결과는 validation.json에 기록한다. 관리 브라우저 연결을 사용할 수 없어 인증된 호스팅 업무 QA는 미수행이며 합성 Worker/jsdom 검사와 구분한다.

원본 일반 조회의 방향·정렬 우선순위·콜레이션, 축별 소계 버튼과 소계 행·상세 이동·인쇄, 페이지분할·기간 비교·그래프·설정 저장, 추가 축과 전역759개 경로의 버튼별 동등성은 남아 있다.
