# API 연동센터 0.4.0

사용자가 요청한 목표는 다른 ERP와 도구가 자료를 주고받는 업무 자동화 ERP입니다. 이번 단계는 커스터마이징의 API인증키발급과 매핑센터를 실제 연동센터로 연결하고, 비공개 서버 API와 이카운트 공식 기능 대조를 제공합니다.

## 구현과 합격 조건

- Worker와 D1에 가상 업무 자료·키 해시·수신 작업·처리 이력을 보관합니다. 기존 브라우저 자료를 자동 교체하지 않습니다.
- API 키는 권한·만료·폐기를 지원하며 원문은 발급 응답에서 한 번만 제공합니다.
- 품목·거래처·창고·전표·재고의 공통 JSON API와 OpenAPI 문서를 제공합니다. 입력은 기존 재고 계산과 검증을 재사용합니다.
- 입력과 수신 이벤트에 중복 방지 키를 적용하고, 동일 키의 내용 변경과 동시 수정을 차단합니다.
- 필드 대응 설정, 수신 자료의 검증·처리·재처리와 송신 대기함을 제공합니다. 외부 송신은 서버의 대상 호스트·비밀 참조 설정이 있어야 실행됩니다.
- 이카운트 공식 공개 안내의 17개 항목을 우리 기능·API에 대응합니다. 로그인 후 매뉴얼의 정확한 경로·필드·인증 규격은 미확정으로 표시하고, 호환 완료라고 표시하지 않습니다.
- 브라우저 자료의 서버 복사는 미리보기 후 명시적으로 실행합니다. 서버 자료를 브라우저로 받을 때도 덮어쓰기 확인을 거칩니다.
- 권한, 만료·폐기, 중복·동시성, 잘못된 자료, 전표·재고, 수신 처리, 송신 제한, 기존 백업 보존을 자동 검사합니다. 비공개 배포 후 실제 API와 브라우저를 별도 확인합니다.

호스팅 접근 범위는 소유자 전용으로 유지합니다. 서비스 호출자는 Sites 서비스 접근 자격과 별도로 이 앱의 범위별 API 키가 필요합니다. 실제 이카운트 업무 쓰기는 이번 가상 자료 검증에 포함하지 않습니다.
