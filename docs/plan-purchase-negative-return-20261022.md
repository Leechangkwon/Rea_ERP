## 내부 저장 결정

기존 purchasereturn/credit를 유일한 저장 전표로 유지한다. 신규 입력 화면은 수량과 고정 금액을 음수로 표시하고 저장 경계에서 처리수량을 양수로 변환하여 기존 convert/document 명령에 전달한다. 별도의 음수 purchase를 동시에 저장하지 않는다. 내부 전표 종류 일치는 원본 매뉴얼의 관찰 조건이 아니며, 사용자에게 보이는 절차·금액·재고·재조회와 원구매 보존으로 평가한다. 기존 양식·백업·메일·반품 참조를 일괄 변환하지 않는다.

세액은 기존 sourceAmounts/returnAmounts의 잔액 배분을 사용한다. 음수에 Math.round를 다시 적용하지 않는다. 기존 반품·교환수량을 함께 빼고, 잔량 초과·원구매/반품 변경·동일 품목의 모호한 행·회계반영 후 수정·초과 지급으로 생기는 음수 채무는 기존 코어의 검증을 유지한다. 이는 호환 보존 정책이며 원본 예외 규칙 합격을 의미하지 않는다. 미완료 VAT 계약 속성이 있는 연구 전표는 명시적으로 거부한다.
