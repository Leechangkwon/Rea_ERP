# 발주계획·발주서 저장/내용유지 0.26.0

발주계획과 발주서의 저장/내용유지를 연결했다. 이미 지원하는 요청·구매와 같이 새 전표를 한 번 저장한 뒤 같은 전표 ID로 계속 수정한다. 같은 gate가 수정 충돌·최신 재읽기·현재 앱 세션의 수정 초안과 F7 저장 후 ID 재설정에도 적용된다.

## 원본 관찰과 REA 경계

원본 발주계획입력과 발주서입력을 각각 열고 저장 옆 분리 화살표에서 저장/내용유지 링크를 확인했다. 발주서의 저장/전표(F7)도 보였다. 실제 저장 링크·버튼이나 주 입력행의 값·번호·선택·이동 컨트롤을 실행하지 않았다. 메뉴를 탐색해 드롭다운을 닫고 발주서조회로 돌아왔다. 회사 자료·세션은 증빙이나 런타임에 보관하지 않았다.

기존78본문을 재확인하고 실제 REA6.4.0 근거14개를 연결했다. 공통 V3의 save_review와 V56의 CreateAndModifyInventoryReviewSlipUserAction은 성공 저장 후 같은 전표 수정 화면으로 재진입하는 분기를 가진다. 하지만 현재 두 입력 페이지의 footer/action registry·override·서버 성공 및 보관 필드의 정확한 연결은 미확인이다. 원본 메뉴 노출과 공통 코드, 자체 구현을 구분한다. 새 GET·원문 실행·새 원본 본문 추가는 없으며 기존 정적/의미 부분·중단 상태를 유지한다. 자체 소스의 AST 참고 자료는 원본 본문 수에 포함하지 않는다.

## 재현한 자체 F7 오류와 수정

수정 전 소스 049a91fe6baecaed7e045511cb22f5328cf5cadc에서 두 종류 각각 새 전표의 F7을 두 번 실행하는 합성 검사를 했다. 예상11건에 실제12건으로 둘 다 실패했다. 저장 뒤 기존 ID로 재진입하지 않아 다음 저장이 또 신규 전표를 만들었다. 두 종류를 기존 저장/내용유지 지원 gate에 포함해 저장된 ID와 기준 스냅샷으로 재진입한 후 로컬 인쇄 미리보기를 연다. 다음 F7/F8은 같은 전표를 수정한다. 계획의 F7은 기존 보조 도구의 로컬 인쇄이며 원본 계획 F7 노출을 주장하지 않는다.

## 자체 보관과 합격 조건

- 신규/기존 수정에서 반복 저장해도 문서 수·재고가 중복 반영되지 않고 기존 행 ID·거래처·메타데이터를 보존한다. 모달의 키·제목·기준을 저장된 ID로 바꿔 깨끗한 닫기와 같은 문서 초안 재개를 지원한다.
- 메뉴 이동·모달 닫기 후 수정 초안은 저장된 전표에 연결한다. 다른 목록에서 같은 문서를 수정하면 오래된 저장은 차단하고 입력값을 유지한다. 최신 재읽기는 확인 후에만 현재 초안을 버린다. 같은 브라우저에 로드된 DB와 앱 세션의 정책이며 브라우저 새로고침·여러 장치·서버 동시성 보장이 아니다.
- 연결 계획의 sourceId/sourceLineId와 행 supplier/progress/custom, 연결된 이전 무ID 행의 호환·잔량을 보존한다. 저장 형식이나 ID 재번호를 추가하지 않는다. 계획 수정 후 기존 발주서 생성 미리보기는 오래된 자료로 차단하고 이미 배분한 수량 미만의 감소도 거부한다.
- 생성 발주서의 generatedFrom/planGeneration·행 lineId·여러 계획의 planAllocations를 보존하며 품목·수량 잠금을 유지한다. 단가·적요 수정 후 반복 저장해도 계획 잔량·연결 구매·재고가 다시 소비되지 않는다. 기존 수량·상태·권한·백업·후속 전표 검증은 바꾸지 않는다.
- 검증·저장 공간 실패·실행 중 권한 상실은 저장 자료와 현재 입력값을 유지한다. 조회 전용 내용유지는 비활성이다. 저장/신규·전자결재 등 다른 미검증 저장 분기는 계속 비활성이다.

신규 합성 검사13개와 기존 관련40개, 집중53개가 통과했다. 수정 전 F7 실패 로그의 해시를 증빙에 기록했다. 독립 검토에서 확정 결함을 발견하지 않았다. 전체 결과는 validation.json에 기록한다. 인증된 호스팅 업무 QA와 원본 저장은 미수행이다. 스키마·저장 레코드 형식 변경은 없다.

전역759경로의 버튼별 동등성, 원본 두 입력의 실제 저장 수신/서버 규칙, 다른 저장 분기·입력 보조, 보고서의 주차/거래유형/관리항목·소계·비교·그래프·설정과 서버 집계/정렬은 남아 있다.
