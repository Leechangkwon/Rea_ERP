## 다음 구현: 요청 BOM 1단계

5. 고정REA6.4.0 원본과 자체 변경 좁은 범위 분석 → 관련 검사 → 필요한 전체 verify:local → 소스 push → 비공개 백업 → 기존 운영만 반영 → 인증 UI/자료 보존 → 모아 기록. 기존0.51.0 검증을 반복하지 말고 새 변경에 필요한 검사로 진행한다.
