# 기초등록 미완성 숫자 입력의 전환·초안 보존

0.89.8 다음 OWN-MASTER-NUMBER-TRANSITION이다. HTML number의 입력 중 `1e`는 value가 빈 문자열이고 validity.badInput은 true다. 기존 추가 숫자/품목 read는 이를 거절하지만 양식 선택은 formActivate 저장 후 repaint에서 읽어 설정만 바뀔 수 있다. 일반 기초등록의 기본 숫자 필드는 raw 초안에서 빈 값이 될 수 있다. 닫기는 read 예외를 처리하지 않아 사용자에게 이유를 안내하지 못한다.

왜 변경하는가: 브라우저가 공개하지 않는 미완성 숫자를 명시적 빈 값으로 취급하거나, 읽지 못한 초안과 다른 양식을 저장하면 안 된다. 양식 변경/편집 진입 전에 초안 읽기를 선행하고, 닫기/이동은 값을 완성하거나 직접 비울 때까지 입력 요소와 이전 설정을 유지하며 오류 필드에 돌아갈 수 있게 한다. 일반 기초등록 기본 숫자도 동일하게 검증한다. 원문을 복원한다고 주장하거나 문자열을 추측하지 않는다. ItemUI 설정 저장에 같은 후행 read 순서가 확인되면 저장 전 snapshot으로 이동한다.

합성 Chromium의 실제 키 입력으로 390/1280px, 품목/거래처/창고·외화·자원 등 기본/추가 숫자를 검증한다. 수정 전 실패·수정 후 저장명령0/설정 byte동일/동일 input 요소와 badInput 유지/닫기 안내·명시 수정/비움/양식 변경/초안 재개/저장·재조회, 기존 계산식과 계정 보호 회귀를 확인한다. 원본 로그인/쓰기·운영 업무/설정 저장0이다.
