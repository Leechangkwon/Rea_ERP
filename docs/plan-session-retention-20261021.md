# REA 로그인 유지 환경변수

사용자 요청: 반복 로그인 줄이기. 현재 기본120분, 최초로그인 기준 절대만료이며 재시작 자체는 세션을 폐기하지 않는다.

서버 전용 REA_STAFF_SESSION_MINUTES(15~43200 정수, 미지정 시 기존 보안설정)를 추가한다. 직원 계정에만 적용하고 고객포털은 기존 설정을 유지한다. 정상 로그인 또는 현재 유효한 세션의 HTML/인증상태 조회에서만 쿠키와 만료시각을 맞춘다. 만료/폐기/비활성/비밀번호 변경/네트워크차단된 세션은 복원하지 않는다. 생성시각+설정기간의 절대한도이며 무제한 연장은 하지 않는다. 비밀번호를 환경변수에 넣지 않는다.

기존 유효세션 연장 시 CAS 안에서 현재 인증/권한을 다시 검사하고 만료시각 및 감사1건만 갱신한다. 기존 자료/양식/계정/메일은 보존한다. 쿠키 HttpOnly/Secure/SameSite/CSRF 유지. 실제 운영은 유효세션·자료백업 확인, 분리된 후보 전체회귀/커밋push 이후 적용한다. 운영설정은 사용자전용 runtime.env에 REA_STAFF_SESSION_MINUTES=43200 한 줄을 추가하며 기존키를 출력하지 않는다. rollback 시 정책값/번들 복원, 계정자료 자동복원/리셋 금지.

정책 변경의 의미: 이미 DB expiresAt이 지난 세션 및 명시 폐기 세션은 복원하지 않는다. 환경변수 축소/제거는 현재 정책으로 즉시 접근을 차단하지만 DB 영구 폐기 작업은 아니다. 관리자가 다시 기간을 늘리면 DB상 아직 유효한 토큰은 다시 허용될 수 있다. 영구 차단은 기존 세션 폐기/로그아웃/비밀번호 변경을 사용한다. 고객 세션은 기존 기간을 따른다.
