# API 매뉴얼 0.5.0

사용자가 직접 연 이카운트 OAPI 매뉴얼의 이용 안내와 판매 API 상세 화면을 읽었습니다. 왼쪽 업무별 목차, 개요, 요청 데이터 형식, 변수·형식·필수 여부 표, Result, 요청/응답 예제와 오류 설명 구성을 참고합니다. 이카운트의 본문이나 회사 자료를 복사하지 않고 우리 실제 API 규격으로 작성합니다.

- `/api-manual`에 독립적인 HTML 설명서를 제공합니다. 연동센터에서 API 매뉴얼 링크로 바로 접근합니다.
- 실제 HTTP 동작 26개(업무·서비스 15개, 소유자 관리 11개)를 모두 수록합니다. 화면 기능만 있고 경로가 없는 기능은 API 제공으로 표시하지 않습니다.
- 원본 매뉴얼에 표시된 이카운트 항목 28개와 양방향 참조를 제공합니다. 우리 전용·기능 대응·부분 대응·인증 개념 참조·미제공을 구분합니다. 원본의 세션 쿼리를 보관하지 않습니다.
- 이용방법·인증·FAQ, 공통·기초등록·영업·구매·생산·이동·쇼핑몰·출력·연동 운영 목차와 문서 검색, 주소별 직접 접근을 지원합니다.
- 호출 방식·주소·헤더·권한·요청/응답 변수·조건부 필수·기본값·보관 한도·중복 방지와 실제 오류를 설명합니다.
- 판매·구매 등 공통 전표 API의 업무별 예제를 제공합니다. 문서 탐색만으로 업무 API를 실행하지 않습니다.
- 요청 시험은 기존 연동센터 화면에서 명시적으로 실행합니다. JSON 명세 다운로드는 보조 기능으로 유지합니다.
- 문서의 경로·예제·오류를 실제 gateway 테스트와 대조하고, 로컬·호스팅 브라우저에서 검색·문서 전환·새로고침·반응형 표시를 확인합니다.
- 기존 서버 자료와 원본 이카운트 업무 자료는 변경하지 않습니다. 같은 소유자 전용 사이트를 갱신하고 관리 페이지에 검증 결과를 남깁니다.
