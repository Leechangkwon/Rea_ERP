# 이카운트 메인·메뉴 재현

사용자가 선택한 범위는 로그인 후 메인 화면과 메뉴다. 메틴 샘플과 동일하게 C:\vibe의 독립 로컬 샘플로 만든다. 원본 계정은 사용자가 우측 브라우저에서 직접 로그인했다. 실제 입력/저장/회사 설정/금융 거래는 수행하지 않는다.

화면에서 읽은 즐겨찾기·10개 업무 영역·59개 메뉴 그룹·248개 항목·511개 세부항목의 계층과 스타일을 재현한다. 일정·전자결재·To Do·업그레이드 위젯, 전체 메뉴 검색, 사이트맵, 즐겨찾기, 최근 메뉴, 업무 탭 전환을 제공한다. 업무 본문은 재현 범위 안내를 표시하며 미확인 입력 폼이나 보고서 수치를 지어내지 않는다.

회사명·사용자 정보·세션 URL·쿠키·비밀번호·실제 업무 데이터를 파일이나 샘플에 보관하지 않는다. 샘플 브랜드와 가상 회사명으로 구분하고 원본 ERP에 요청을 보내지 않는다. 즐겨찾기/위젯 구성은 샘플의 브라우저 저장소에만 저장한다.

원본에서 관찰한 공개 CDN 스크립트를 인증 없이 내려받아 REA 6.4.0의 정적 JavaScript 분석에 사용한다. 원본 JavaScript는 샘플에서 실행하지 않는다. REA 결과의 정확한 범위·소스 해시·UI 관찰과 새 구현의 경계는 evidence와 README에 남긴다.

개발은 buildless HTML/CSS/JS. 서버는 127.0.0.1:8780에 dist만 제공한다. 메뉴 원본 계층 수/이름과 브라우저 검색·즐겨찾기·탭·사이트맵·일정·위젯 구성의 실제 동작을 검증한다. 공개 배포는 이번 로컬 작업에 포함하지 않는다.
