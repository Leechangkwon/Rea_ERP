## 이번 구현 계약

1. 비교자료가 있는 단가요청은 현재 원본과 일치하는 ready 상태에서 확정가·확정 거래처를 행별 투영한다. 미확정/요청가 확정 행은 거래처를 추정하지 않고 사용자의 발주 거래처를 유지한다. 비교자료 없는 과거 원본은 기존 동작을 보존한다.
2. 거래처 필터와 표시를 확정행 기준으로 연결한다. 서로 다른 확정 거래처를 한 발주서에 섞지 않고 사용자가 행을 골라 분리한다. 최저가/첫 거래처 자동 선택 없음.
3. 후보 조회→적용→첫 저장에 비교 수정번호와 원본 상태를 재검사한다. 저장된 발주는 비교 선택 변경으로 자동 가격 변경하지 않는다. 기존 발주 수정/취소/복원·백업 보존.
4. 실제 sourceLineId만 잔량 연결에 사용한다. 중복 품목·공백 포함 라인 ID 보존. 잔량 합산은 기존 원본행 기준 유지.
5. 비교 원문 가격 문자열은 근거에 보존. 기존 숫자 저장형에서 정확히 왕복하지 못하는 가격은 조용히 반올림하지 않고 적용을 거절한다. 전역 금액 엔진은 이번 변경 범위 밖.
6. 피커 내용복사/잔량연결, 목록의 후속 발주 생성, 편집기 원본 선택 경로 모두 동일 계약 사용.
