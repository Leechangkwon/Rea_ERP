원본 구매조회 메뉴511에서 현재12열과 DOM 항목 ID를 직접 확인했습니다. 기본 목록은 선택/일자-No./거래처명/사원(담당)명/창고명/품목명(요약)/상태/금액합계/인쇄/불러온전표/최초작성자/최초작성일자 순서입니다. 자체 상태는 확인 여부와 진행상태를 함께 표시합니다. 원본 progress_status와 confirm_type은 별도 필드이므로 자체 확인 여부 하나를 원본 상태와 같다고 해석하지 않습니다.

## 자체 표시와 기존 양식

금액은 기존 C.totals, 품목은 자체 첫 품목 요약, 불러온전표는 기존 sourceId를 표시합니다. 원본 amt/prod_summary/관계 표시와 공식이 같다고 단정하지 않습니다. 기존 createdBy/createdAt 문자열이 있으면 보이고 없으면 미기록입니다. 현재 로그인 사용자를 과거 작성자로 넣거나, 원본 시간대·표시 형식을 추정해 변환하지 않습니다.

인쇄 칸은 고정 ‘인쇄’ 링크라는 원본 관찰에 맞춰 비활성 ‘인쇄’ 버튼과 연결 미검증 설명을 제공합니다. 인쇄 여부·횟수·이력 값으로 보지 않습니다. CSV에는 해당 미지원 기능을 명확히 적습니다. 실제 원본 최종 인쇄 action을 확인하지 못했으므로 새 셀의 클릭은 연결하지 않습니다. 기존 하단 자체 인쇄 기능은 유지합니다. 상태 셀도 자체 두 상태의 표시만 제공하며, 기존 하단 확인/미확인 변경을 사용합니다. 전체 선택과 하단 확인 변경 후에도 진행상태는 독립적으로 유지합니다.
