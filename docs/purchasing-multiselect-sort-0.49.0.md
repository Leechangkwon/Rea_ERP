# 구매 조회 다중 선택·수정일자순 · 0.49.0

네 조회의 기준자료 검색에 다중 선택을 추가했다. Search(F3) → 해당 항목의 다중 선택 → 검색/체크 → 적용(F8)으로 조건을 준비하고 목록의 검색(F8)으로 조회한다. 같은 항목은 OR, 항목 사이는 AND이며 계획은 같은 품목행에서 거래처/품목 조건을 함께 판단한다. 팝업은 50행씩 표시하고 페이지·검색을 바꿔도 선택을 유지한다. 적용은 1~200개이며 닫기/Escape는 취소, 조건의 개별 해제/전체 해제로 선택을 지운다. 기존 단일 선택과 기존 검색 양식의 ID·이름·기본값·숨김을 유지한다.

원본에서 체크박스를 확인한 요청·구매에는 수정일자순(정렬)을 추가했다. 실제 수정 시각 최신순이며 같거나 기록 없는 전표는 기존 순서를 유지한다. 원본 서버의 방향·동률 규칙은 미확인인 자체 정책이다. 현재 원본 발주서·계획 검색에 없는 정렬 항목은 추가하지 않았다. 성공한 실제 구매 전표 변경에서만 선택적 modifiedAt을 기록하고, 무변경/실패/조회·양식 변경은 수정 시각을 바꾸지 않는다. 들어온 전표의 임의 시각은 저장에 사용하지 않는다. 옛 v2 자료에는 시각을 만들어 넣지 않으며 보관 이력도 정렬에 활용한다. 시각은 200건 이력 범위를 넘어도 전표에 보존한다. 다른 업무 전표의 자유 메타데이터는 기존대로 둔다.
