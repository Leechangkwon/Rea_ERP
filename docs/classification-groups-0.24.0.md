# 거래처·프로젝트 그룹과 구매 집계 0.24.0

거래처그룹1별·2별과 프로젝트그룹1별·2별을 구매 집계에 추가했다. 기존 축과 함께 열아홉 종류에서 최대 다섯 축을 선택한다. 기초등록에 독립적인 그룹 문자열 두 개를 추가하고 등록·조회·목록 CSV·백업 검증 및 기존 거래처 API/서버 CSV 가져오기를 연결했다.

## 원본 관찰과 공개 근거

원본 네 축을 각각 조회해 축 이름, 수량, 공급가액, 부가세, 합계의 다섯 열을 확인했다. 원본 업무·설정 저장, 주 입력행 조작은 실행하지 않았고 회사 기록·그룹 값·금액·세션을 보관하지 않았다.

실제 REA6.4.0의 기존 근거22개를 대조했다. summary_cust_group1/2와 summary_pjt_group1/2는 V5의 cust_group1/2·pjt_group1/2, V56의 cust$cust$cust_group1/2·pjt$pjt$pjt_group1/2 검색 대상으로 변환된다. 이는 집계 행 드릴다운 검색 경로다. 별도 레거시 DTO가 선택 SID를 CUST_GROUP1/2·PJT_CODE1/2에 전달하더라도 일반 GROUPBY·SID와 코드/명 관계·현재 표시·과거 그룹 기준의 증거로 확대하지 않는다. 새 GET·원문 실행은 없고 누계78본문/19,149,569B와 기존 부분·시간/메모리 중단을 보존한다.

## 자체 등록과 호환 정책

- partners/projects의 group1/2를 각각 선택 문자열 필드로 선언했다. 각 200자 이하이며 빈 문자열을 허용한다. 없는 필드는 계속 생략하고 기존 v2 백업을 변환 없이 받는다. 잘못된 타입과 길이는 저장·백업·API·CSV에서 같은 검증으로 거부한다.
- 등록 화면의 신규/수정과 두 그룹을 포함한 목록·CSV를 연결한다. 기존 전표 참조와 특별단가의 priceGroup은 변경하지 않는다. 그룹 문자열 외에 독립 코드/명/SID 마스터나 계층 관계를 만들지 않는다.
- 기존 POST /api/v1/partners와 서버 거래처 CSV 가져오기 허용 필드에 group1/2를 추가한다. API 문서에 타입·길이·빈 값 정책을 안내한다. 기존 필수값·권한·수정 번호·중복 요청·가져오기 미리보기 규칙은 유지한다. 프로젝트 전용 API·CSV 가져오기 경로를 새로 만들지는 않는다.
- 브라우저 업무 자료와 D1 API/서버 CSV 자료는 기존 별도 영역이다. 이번 필드 추가가 자료 동기화나 실 ERP 연결을 뜻하지 않는다. 관계형 DB 스키마 변경은 없고 저장 레코드의 선택 속성만 추가한다.

## 집계 기준과 합격 조건

거래처 그룹은 행별 supplier가 있으면 해당 거래처, 없으면 전표 partner의 현재 등록정보를 사용한다. 프로젝트 그룹은 전표 project의 현재 등록정보를 사용한다. 동일 문자열은 합치고 없는 값은 미지정으로 묶는다. priceGroup이나 groupNName을 추정해서 사용하지 않는다. 현재 등록정보 변경은 다음 조회부터 기존 전표에도 적용된다. 검색 도움말·성공 결과·인쇄에 이 기준을 표시한다.

날짜·행 거래처·취소 제외, 자체 행별 금액과 반올림 후 합산, 혼합 통화 거부, 최대 다섯 축·방향·명시 정렬·정렬 후보 교체, 성공/대기 조건 복원과 조회 전용 CSV·인쇄를 유지한다. 기존 품목그룹 집계 기준도 함께 표시한다.

신규 합성 검사16개와 집중 검사136개로 네 축·행 거래처 우선·빈 값·현재 등록정보 변경·다섯 축과 금액/records 대응, 저장/백업 경계, 기초등록 두 화면·목록 CSV·원래 전표 보존, API 저장/재전송/실패 무반영, 서버 CSV 미리보기/가져오기/이전 열 호환, 성공/대기 조건과 조회 전용 출력 등을 검증했다. 독립 검토에서 기존 저장 목록 양식의 위치 기반 열 ID가 어긋나는 문제를 발견해, 새 그룹 열을 기존 사용여부 뒤에 덧붙이고 이전 양식의 표·CSV 회귀 검사를 추가했다. 전체 결과와 독립 검토는 validation.json에 기록한다. 인증된 호스팅 업무 QA는 미수행이다.

주차·거래유형·관리항목 등 추가 축, 원본 소계·상세 이동·기간 비교·그래프·설정 저장·서버 집계와 정렬, 원본 SID/분류 이력, 전역759경로의 버튼별 동등성이 남아 있다.
