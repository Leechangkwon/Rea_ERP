# 발주요청조회 F3 검색 단축키 — 2026-10-19

## 현재 관찰과 범위

Windows 채팅에서 기존 WSL Ego 프로필의 사용자 로그인을 이어받아 ERP 셸과 발주요청조회(E040315, 메뉴 505)를 직접 확인했다. 관찰 경로는 재고 I → 구매관리 → 발주요청 → 발주요청조회다. 목록 열과 검색 항목 19개의 라벨·컨트롤 종류만 기록했으며 입력값, 전표 행, 회사 자료, 인증 정보와 세션 URL은 읽거나 인계하지 않았다.

원본에서 검색이 닫힌 상태에서 F3을 누르면 검색 영역이 열리고, 다시 F3을 누르면 닫힌다. 각 키 입력 뒤 350ms 동안 화면 전환을 기다린 뒤 확인했다. 즉시 읽은 이전 탐색에서는 전환 전 상태가 남아 있었으므로 그 결과를 합격 근거로 사용하지 않는다. 원본 저장·삭제·발송·설정 저장 및 주 입력행 조작은 없었다.

원시 관찰: `.artifacts/ego-authenticated-20261019/request-observation.json`, `f3-observation.json`. 공개 목록 JS 두 개는 같은 폴더에 인증 없는 GET으로 분리 확보하고 고정 REA 6.4.0 CLI로 분석한다. 공개 코드의 검색 액션 후보와 실제 키 동작 관찰을 구분하며, 키 디스패치의 정적 연결까지 확인했다고 주장하지 않는다.

## 수정 대상과 사용 예

- `dist/inventory-ui.js`의 `requestList`: 기존 Search(F3) 버튼과 같은 펼치기/접기를 키보드에서도 실행한다. 이번 새 동작은 발주요청에 한정한다.
- `tests/request-list.cjs`: F3 펼치기/접기, 기본 브라우저 동작 방지, 검색어·선택·자료 보존, 다이얼로그와 수정키 이벤트 격리를 확인한다.
- `tests/browser/request.spec.cjs`: localhost 합성 화면에서 실제 F3 입력과 포커스, 검색 및 기존 선택 상태 보존을 확인한다.

사용 예: 발주요청 빠른검색에 포커스 → F3 → 상세 검색 표시 → F3 → 접기. 원본 업무 자료와 검색 서버 호출은 실행하지 않으며 검색 피커·19개 항목 전체·Option·서버 동등성은 이번 구현 범위가 아니다.

## 합격 조건

F3은 기존 버튼과 같은 동작을 하고 조회 상태·선택·저장 자료를 보존한다. 기존 입력/보조 다이얼로그의 F3을 목록이 가로채지 않고 Ctrl/Alt/Meta 조합이나 이미 처리된 이벤트는 건드리지 않는다. 관련 Node/jsdom 검사와 localhost Playwright 검사를 통과한다. 기존 미커밋 변경을 보존하고 배포·운영 설정·의존성·저장 스키마를 변경하지 않는다.

## 실행 결과

- 실제 Ego 로그인 후 발주요청조회 진입과 F3 두 번의 펼치기/접기를 확인했다. 회사 자료와 입력값이 없는 메뉴 영역만 `request-navigation.png`로 저장했다.
- 익명 공개 GET 2건, 합계 1,470B의 목록 진입 로더를 확보했다. REA 6.4.0 종료 0, 파싱 2/오류 0, 의미 노드 134개, 자원 제한에 따른 부분 분석 없음. 이 작은 로더는 외부 목록 구현으로 위임하므로 검색 액션·키 디스패치 전체 분석으로 해석하지 않는다. 기존 86본문 누계를 새로 계산하거나 증가시키지 않았다.
- 자체 `requestList` 화면의 F3 누락을 보완했다. 기존 버튼을 재사용하며 닫힐 때 빠른검색으로 포커스를 돌려 연속 F3 입력이 가능하다. 수정키·반복키·입력 조합·이미 처리된 이벤트와 다이얼로그 이벤트는 가로채지 않는다. 다른 화면의 기존 F2/F8 흐름을 보존했다.
- 최종 수정 후 관련 Node/jsdom 검사 15개, localhost Playwright 5개, 환경 검사, 빌드, `node --check`, `git diff --check` 통과. 그 전 실행한 모달·이력·목록 회귀 검사 39개도 통과했으며 마지막 포커스 보완은 위 15개와 5개로 다시 확인했다. 전체 앱 검사는 이번에 다시 실행하지 않았다.
- 관찰/분석/구현 연결의 보관 근거는 `evidence/browser-rea-linux-20261019.json`이다. 앱은 로컬 0.42.0의 미커밋 수정 상태이며 배포·버전 상승·현재 릴리스 누계 변경은 없다.
- 다음 조사: 발주요청 검색 피커와 Option의 하위 항목. 서버 검색·권한·저장·출력·삭제·발송 및 원본 동등성은 미검증이다.
