# 로그인 화면과 매뉴얼 안내 0.5.1

사용자는 ERP 화면의 로그인·로그아웃을 선택했습니다. 추가 요청은 API 매뉴얼 버튼의 글자 대비와 설명입니다.

- Sites가 제공하는 ChatGPT 로그인·로그아웃과 인증된 요청 식별자를 사용합니다. 별도 OAuth·비밀번호·세션 저장소를 만들지 않습니다.
- `/login` 화면에서 현재 로그인 여부, ERP 열기, 로그인, 로그아웃을 제공합니다. 상단에 로그인·로그아웃과 계정 정보를 표시합니다.
- 인증 의존 HTML은 서버에서 실제 식별자로 렌더링하고 캐시하지 않습니다. 소유자 전용 사이트 접근 범위를 유지합니다.
- 로그인 후에는 같은 사이트의 원래 메뉴로 돌아갑니다. 외부 주소와 인증 경로로의 반환은 차단합니다.
- API 매뉴얼 링크는 흰 글자와 명확한 제목·설명을 갖춘 안내 영역으로 교체합니다. 업무·관리 API 전체, 이카운트 대조, 요청·응답 예제 범위를 표시합니다.
- 로컬 모의 식별자 검사와 호스팅된 실제 로그인 화면·로그아웃·재로그인 결과는 구분합니다. 기존 업무 자료를 변경하지 않습니다.
- 0.5.1 버전, 자동 검사·브라우저 검사·동일 비공개 사이트 배포와 관리 페이지 기록을 완료합니다.
