# 구매 검증창의 찾기와 정렬 0.11.2

2026년 10월 18일. 사용자가 다른 브랜드의 운영 계정으로 로그인한 새 탭을 확인했다. 기존 탭은 다음 화면 이동에서 로그인 화면으로 돌아갔으며 새 탭의 로그인은 별도로 확인했다. 새 계정은 사이트맵에 7개 상위 영역을 표시하고 계정등록 메뉴는 표시하지 않았다. 이 차이를 전체 메뉴의 삭제나 권한 오류라고 단정하지 않는다. 이 계정도 운영 계정으로 취급하며 원본 회사 자료·설정을 저장·삭제·발행하지 않았다.

## 직접 관찰

구매입력 E040303의 검증창에서 찾기(F3)를 누르면 같은 창의 도구 모음에 검색 입력이 표시된다. 빈 행에서 관찰용 문자열을 입력하고 Enter를 눌렀으며 자료 추가나 별도 품목선택창은 나타나지 않았다. 실제 품목이 입력된 원본 행에서 검색·반복·강조 동작은 확인하지 않았다. 관찰용 문자열은 지우고 창을 닫았다.

정렬은 별도 FM080P_02 창이다. 초기 세 행에 순서·정렬기준·정렬방법이 있고 기준이 없으면 방향 버튼이 비활성화된다. 이 계정의 선택 목록은 없음·품목코드·품목명·BOX·수량이었다. 첫 기준을 품목코드로 선택한 뒤 방향을 오름차순에서 내림차순으로 전환했다. Option의 기본값설정 항목을 확인하고 적용·설정 저장 없이 닫았다. 초기 세 행은 관찰값이며 원본의 최대 기준 개수가 세 개라고 입증하지 않는다. 입력 열과 정렬 후보는 회사 양식에 따라 달라질 수 있다.

## 공개 소스와 REA

이번에 계정등록 E010107 원문 37,371B와 정렬창 원문 6,357B를 새로 확보하고 실제 REA 6.4.0 정적·의미 분석을 실행했다. 둘 다 파싱 오류 0이다. BarcodeVerification 7,379B는 다시 가져온 SHA256이 기존 원문과 같아 중복 합산하지 않았다. 공유 동작을 찾기 위해 현재 DOM이 참조하는 inventorylib.common 93,751B와 contentsform 196,812B도 추가 분석했다. 이 두 파일에는 해당 searchText·rebuildContent·F3 정의가 없어 검색 동등성은 미확인이다. 이전 49개와 합쳐 고유 원문은 53개·8,150,530B이다. 정적 완전 52개·부분 1개, 의미 완전 51개·부분 1개·시간 중단 1개의 경계는 유지한다. source corpus 수량은 버튼 구현 수량이 아니다.

FM080P_02는 중복 열을 거절하고, 일반 적용에서는 빈 정렬 조건도 거절한다. 방향값 변환과 정상 적용 메시지는 정적 근거이며 실제 부모 창 정렬 결과는 별도 경계다. 기본값설정 저장은 별도 서버 요청이다. 정확한 URL·해시·위치와 미해결 호출은 `evidence/global-rea-20261018/verification-toolbar/`에 있다. 원문과 분석 IR은 실행 자원에 포함하지 않는다.

계정등록 소스의 신규·수정은 별도 편집창, 상태 변경·삭제는 서버로 위임한다. 계정 편집창과 서버 검증을 확인하지 않았으므로 회계 계정 기능을 구현 완료로 추가하지 않았다. 이번 변경은 기존 759개 경로 중 487개 안내 카드라는 전역 기준을 바꾸지 않는다.

## 자체 구현과 합격 조건

구매 검증창의 찾기(F3)는 현재 검증 행의 코드·수정된 품목명·규격·수량을 검색한다. 일치 수와 현재 위치, 다음 찾기, 강조와 닫기를 제공한다. 이 검색의 대소문자·유니코드 정규화·반복·강조 세부 규칙은 자체 구현이며 원본 공유 검색 위젯의 동등성이 확인된 것은 아니다.

정렬창은 세 단계 기준과 방향을 임시 편집하고 적용(F8) 때만 검증 행 순서를 바꾼다. 자체 검증 열인 품목코드·품목명·규격·수량을 사용하며 BOX 환산은 제공하지 않는다. 마스터 값 대신 수정된 검증 행 값을 비교하고 수량은 숫자로 비교한다. 동률은 기존 순서를 보존한다. 빈 기준·중복 기준은 오류로 남기고 창을 유지한다. 열려 있는 동안 검증 행이 바뀌면 적용을 거절한다.

취소와 Escape는 검증 행을 유지한다. 부모 창을 닫으면 하위 정렬창도 닫힌다. 찾기·정렬·검증·다시 작성은 원본 구매 초안·업무 DB·재고·전표 적용 콜백을 변경하지 않아야 한다. 조회 전용·잔량 연결 전표에서도 독립된 검증 행만 다룬다. 이 조건을 합성 자료로 검사한다.

## 남은 범위

원본 공유 검색 위젯의 세부 검색 규칙, 정렬 비교 규칙과 부모 수신, BOX 환산, 기본값설정 저장, My품목과 바코드 하위 분기, 불일치 결과의 별도 팝업은 계속 미확인 또는 미구현이다. 현재 비교 결과는 입력 중 갱신되는 자체 인라인 표이며 원본의 별도 결과 팝업과 구분한다. 실제 운영 계정에서 저장·삭제·발행 결과를 시험하지 않는다.

전체 자동 검사·릴리스 검사·빌드 결과는 `evidence/global-rea-20261018/verification-toolbar/validation.json`에 기록한다. Sites 관리형 미리보기용 로컬 브라우저 도구가 없어 jsdom으로 검증하며, 배포된 ERP에 실제 로그인한 업무 화면 검증과 구분한다. 저장 형식과 DB 스키마는 바꾸지 않는다.
