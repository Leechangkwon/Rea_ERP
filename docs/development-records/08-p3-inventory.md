# P3 — 재고·창고·이동·실사·물류

## 당초 계획과 현재 상태

구매 재고 영향 검증 뒤 창고·품목·시리얼 수불, 이동/실사/조정, 취소·마감, 바코드/WMS를 검증하는 단계다. 초기 재고 코어·전표·현황·CSV/인쇄 기능은 이미 존재한다. 0.10 재고현황에는 창고별 수량·금액과 수불 대사의 합성/브라우저 근거가 있다. 이것을 P3 전체 매뉴얼 합격으로 올리지 않는다.

## 기존 → 앞으로의 변경과 이유

단일 기능의 수량 합산 → 원본 전표부터 창고/품목/시점별 원장까지 연결하여 대사한다. **왜:** 조회 합계가 맞아도 입고·이동·반품·취소에서 특정 창고 잔량이 틀릴 수 있기 때문이다.

화면의 바코드 버튼 → 실제 장비·입력 형식·중복 스캔·실패 복구 검증을 추가한다. **왜:** 브라우저 버튼 클릭은 스캐너/WMS가 같은 결과를 냈다는 증거가 아니기 때문이다. 아직 확인하지 않은 수량 반올림·최소구매단위를 추정 구현하지 않는다.

## 선행 조건·합격 기준

P2.4의 구매/반품 수불·마감 계약과 공통 기초자료/권한을 확인한다. 합성 수불 대사·저장/재조회·취소·동시 수정·실제 장비 결과를 구분하고, 기존 창고/재고 자료를 보존해야 한다. 장비 접근이 없으면 그 범위를 미완료로 남긴다.
