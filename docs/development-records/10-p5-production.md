# P5 — BOM·MPS/MRP·생산·외주·품질·원가

## 당초 계획과 현재 상태

재고/수주·구매를 선행 조건으로 소요량, 투입/실적, 불량/외주, 원가 시나리오를 검증한다. 현재 0.52.0의 요청 입력 BOM 1단계 소요량 불러오기는 구현 이력이다. **다단계 BOM·생산계획·MRP·원가 전체가 완료된 것은 아니다.**

## 기존 → 앞으로의 변경과 이유

요청 생성에 필요한 1단계 소요량 → 실제 매뉴얼에 따른 다단계·시점별 BOM·재고/발주/생산 중복 차감과 계획을 분해한다. **왜:** 1단계 곱셈이나 보유재고 차감 helper로 전체 소요량 산정과 납기 계획을 설명할 수 없기 때문이다.

수량/단가의 공통 계산 → 공정 투입·실적·불량·외주비와 원가 반영 기준을 각각 확인한다. **왜:** 정상 수량과 실제 원가·재공은 서로 다른 업무 결과이며 근거 없이 같은 식을 사용할 수 없기 때문이다.

## 선행 조건·합격 기준

관련 본문과 수치 예제·단위·반올림·시점 계약을 확보하고, 원재료→투입→실적/불량→재고/원가를 대사한다. 현재 최소구매단위/계획 수량식의 미확인 부분은 그대로 남기며 제품 소개의 선택항목을 수치 공식으로 간주하지 않는다.
