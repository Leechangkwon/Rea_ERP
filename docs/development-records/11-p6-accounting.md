# P6 — 회계·자금·세무·결산·고정자산

## 당초 계획과 현재 상태

업무 전표·원장 계약을 전제로 차대, 채권/채무, 원장·신고 자료, 마감 및 외부 검증을 수행한다. 현재 구매 부분 처리의 재고/채무 수치와 회계반영 보호를 검증한 범위가 있지만 회계·세무 전체 합격은 아니다.

## 기존 → 앞으로의 변경과 이유

구매 합계/채무 숫자 확인 → 전표·원장·차대·결산/신고 간 대사로 확장한다. **왜:** 구매 합계가 맞아도 계정과목·귀속기간·상대 계정·취소/마감 결과는 따로 틀릴 수 있기 때문이다.

공통 세율·반올림 가정 → 선택된 거래유형/회사 숫자 정책과 실제 VAT 입력/차액 배분 계약을 확인한다. **왜:** 현재 7사례/5충돌의 미완료 VAT 연구를 세무 결과로 설치하면 과거 금액과 신고 기준을 훼손할 수 있기 때문이다. 기존 금액을 자동 재계산하지 않는다.

## 선행 조건·합격 기준

시점별 공식 자료·적용 범위·업무 전표 연결을 확보한다. 합성 대사와 실제 회계/외부 수락을 구분하고, 마감/반영 자료 변경 보호·취소 이력·재조회·보존을 확인한다. 실제 신고·금융 실행은 별도 명시 요청 없이 수행하지 않는다.
