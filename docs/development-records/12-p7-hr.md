# P7 — 인사·근태·급여·연말정산·UserPay

## 당초 계획과 현재 상태

권한·회사/신원·회계 계약을 기반으로 인사 조회 범위, 근태·급여/공제, 명세/집계와 시점별 규칙을 검증한다. 계정 로그인·등록 담당자 선택이나 권한그룹 조건양식의 존재는 인사/급여 기능 완료가 아니다.

## 기존 → 앞으로의 변경과 이유

담당자 코드/로그인 역할 → 실제 직원 신원·소속·재직/권한과 급여 조회 범위를 분해한다. **왜:** 업무 담당자 선택권과 다른 직원의 개인 급여 조회권은 같은 권한이 아니기 때문이다.

정적인 급여 화면 → 해당 시점의 근태/공제 규칙·집계·명세·회계 연결을 검증한다. **왜:** 시점이 다른 계산 규칙이나 근거 없는 기본값을 사용하면 명세와 장부가 달라질 수 있기 때문이다. 현재 문서에 없는 산식·기본값은 만들지 않는다.

## 선행 조건·합격 기준

공식 본문/기준 시점, 두 사용자 이상의 열람/수정 격리, 공용 저장·동시 수정, 급여/공제와 장부 대사가 필요하다. 검증에는 가상 인적자료를 쓰고 실제 급여 명세 발송은 명시 요청 없이 실행하지 않는다.
