# 구매현황 집계 0.15.0

구매현황에서 현황/집계를 선택하고 품목별·거래처별 조건을 최대 두 개 지정해 조회한다. 조건 없이 조회하면 안내를 표시하고 검색 폼을 유지한다. Search(F3)로 조건을 다시 열고, 다시작성으로 현황·라인별 기본 조건으로 돌아간다. 원본은 선택할 때 빈 집계조건을 추가하지만 최대 개수는 확인하지 않았다. 자체 구현은 두 조건까지 지원한다.

## 원본 근거와 적용 범위

로그인된 원본 구매현황에서 조회만 수행했다. 현황의 품목별 구분과 집계의 집계조건은 서로 다른 컨트롤이다. 집계조건1에 품목별을 넣어 조회하면 품목별·수량·공급가액·부가세·합계 5열이 나오고, 집계조건2에 거래처별을 추가하면 그 순서대로 6열이 나온다. 원본의 숫자·회사 자료·세션 URL을 보관하지 않았다. 두 조건 결과에는 colspan=2의 소계 행과 subtotal 수치 필드가 있으며 실제 소계 공식과 상세 이동 결과는 미확인이다. 자체 표는 그룹별 본문과 하단 전체 합계를 제공하며 원본 소계 행을 재현했다고 표시하지 않는다.

현재 회사의 현황 양식은 16열이며, 같은 '규격' 이름도 품목그룹2에 연결돼 있었다. 이전 관찰의 19열을 유지하되 특정 회사의 양식명을 앱에서 제거하고 'REA 구매 내역 양식'으로 표시했다. 현 계정 양식의 열 이름을 기존 앱 필드로 임의 치환하지 않았다. 회사별 동적 출력 양식 전체의 재현은 남아 있다.

DOM에서 실제 관찰한 공개 URL 5개를 각 한 번 GET하고, 실제 REA6.4.0으로 정적·의미 분석했다. 새 고유 V3 본문3개는586,127B이고 V56의 새 GET2개는 기존 SHA와 같아 누적에 더하지 않았다. 고유 코퍼스69개·10,214,621B, 정적68완료+1부분, 의미67완료+1부분+1시간초과 미확인이다. 새 다섯 분석 실행은 오류·시간초과0이다. V3 위젯이 현재 V56 F3 화면에 실제 연결됐는지는 미확인이며, 정렬·비교·다운로드의 동적 의존성과 서버 집계 공식은 분리해서 기록했다. REA 후보나 호출 수를 검증된 버튼 수로 세지 않는다.

## 자체 집계와 합격 조건

기존 REA 전표의 조회 조건을 먼저 적용하고 활성 구매행을 코드별로 묶는다. 수량·공급가액·부가세·합계는 각 행의 할인과 전표별 반올림 규칙을 적용한 값의 합이다. 집계 금액에 세율을 다시 곱하지 않는다. 행별 거래처가 있으면 전표 거래처보다 우선하며 이름이 같아도 코드가 다르면 다른 그룹이다. 집계 결과를 임의의 첫 전표 상세로 연결하지 않는다. 서로 다른 통화는 환산 없이 합산하지 않으며 조건을 좁히도록 안내한다. 이러한 계산·검증은 자체 정책이고 원본 서버의 금액·환율·소계 동등성 근거가 아니다.

| 흐름 | 합격 조건 |
| --- | --- |
| 품목별 집계 | 5열, 같은 품목을 한 번만 합산, 원본 REA 전표 불변 |
| 품목·거래처 두 조건 | 선택 순서대로 6열, 행 거래처와 중복 이름의 코드 구분 |
| 조건 오류 | 빈 조건·중복·미지원 조건·역전/불가능한 날짜 차단 |
| 금액 | 행별 할인·서로 다른 세율·반올림을 보존한 합산 |
| 통화 | 혼합 통화 합산 차단, 조건으로 분리한 통화 표시 |
| F3/다시작성 | 조건 재개·기본 모드 초기화, 업무 자료 변경 없음 |
| 내보내기·인쇄 | 마지막 성공한 집계의 열·값·통화 제목 유지, 읽기 전용 권한에서도 조회·출력 |

관련 보고서·통합 검사32개와 인접 저장 검사9개, 합계41개가 통과했다. 전체 검사와 릴리스 결과는 `evidence/global-rea-20261018/purchase-summary/validation.json`에 기록한다. 구매실 등 다른 화면에서 전표를 저장한 후에도 집계 모드·마지막 성공 조건을 유지하고 최신 금액을 다시 조회한다. 미적용/오류 상태의 현재 조건은 별도로 보존한다. 새 자료가 혼합 통화가 되어 재조회에 실패하면 예전 표·출력 결과를 제거하고 조건을 다시 연다. 저장 형식·DB 스키마를 바꾸지 않았다. 관리 브라우저의 로컬 미리보기 연결이 없어 대체 브라우저를 시작하지 않았으며 호스팅 계정으로 로그인한 업무 QA는 미검증이다.

## 남은 작업

원본 소계·집계 상세 이동·세 조건 이상·그 외 집계축·전년/전월/전주/전일 비교·그래프·회사별 동적 양식·Excel 파일 보안 규칙은 남아 있다. 전역759개 경로 중487개 안내 등 기존 기능 범위는 유지하며 이 릴리스로 전역/버튼별 재현 완료를 선언하지 않는다. 이후 원본 조사는 조회 전용 화면·정적 DOM·공개 코드로 이어가고 주 입력행은 조작하지 않는다.
