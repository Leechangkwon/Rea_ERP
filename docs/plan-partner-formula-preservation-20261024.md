# 거래처 및 공통 기초등록 사용자항목 원문 보존

0.89.6의 OWN-PARTNER-FORMULA-PRESERVATION 후속이다. 품목의 전용 입력 경로와 달리 거래처/창고 등 공통 기초등록은 숫자 유형 변경 때 원문을 공란으로 만들고 계산 오류 뒤 결과칸을 초안 원문으로 읽는다. 왜 변경하는가: 양식 전환은 기존 거래처 값이나 미저장 초안을 지우는 작업이 아니기 때문이다.

기초등록에만 보존 옵션을 적용한다. 표현 불가능한 숫자 원문은 문자 입력으로 보존·안내하며 숨긴 항목도 수정할 수 있게 일시 표시한다. 명시적 수정/공란 전 저장은 차단한다. 초안은 원문·계산 캐시·일반 입력을 유지하고 계산 결과 화면은 오류 시 공란으로 둔다. 계산 결과 DOM을 원문으로 삼지 않는다. 문서 입력/검색의 기존 configureGrid 경로, FormCore/schema 및 품목 전용 경로는 유지한다.

현재 운영79cf964 기반 격리 후보에서 신규 Node/브라우저 수정 전 실패, 수정 후 관련·전체 회귀와 자체 REA를 검증한다. root의 미완료 VAT/매핑을 전체 복사하거나 빌드하지 않는다. 검증 후 커밋/push·기존 운영 배포 및 계정/자료/양식/메일 보존을 확인한다. 원본 조작·운영 양식/업무 저장·발송0, 전체 매뉴얼 완료0 유지.
